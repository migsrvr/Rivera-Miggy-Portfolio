# Backend implementation contract

Approved full backend/admin plan, 2026-10-26. Existing ESM static portfolio remains default preview; hosted deployment is not in scope. Real local Supabase Auth/Postgres/Storage; no production fake persistence/login. Local-only owner can be generated to ignored credentials file without printing secrets.

## Shared records
Entry = {collection,id,data,position,visible,sample,archived,updated_at?}. Collection one of profile, projects, experiences, credentials, community, gallery. id immutable lowercase kebab string <=80. profile singleton id profile. data carries original source fields; projects merge deployed+recorded fields with kind deployed|recorded, featured boolean, featureOrder number, stages array; featured summary derives from role/purpose. Community data.category hackathons|leadership|organizations. Credentials data: name,provider,logo,url,linkLabel,date?,category?. Experience data role,organization,description,logo,startDate?,endDate?. Gallery data title,caption,image,alt,date?. Profile retains original fields, optional photoCaption. Assets referenced as asset:<uuid> or existing /assets/ paths. Relationships={project_id,experience_id,sample}. Assets={id,storage_path,original_name,mime_type,size,visibility:private|public,archived,created_at?}. Release={id,state:building|ready|failed,snapshot,error?,created_at,published_at?}.

## Model/build interface
src/model.mjs exports COLLECTIONS (array), entrySchemas (Zod registry), validateEntry(collection,entry) => sanitized Entry (throw ZodError), createSeedDraft() => {entries,relationships}, validateDraft(draft) => void (allow unassociated projects, enforce link targets), toContent(draft) => original renderer data shape, getRoutes(content) => original routes plus dynamic experience routes. draft contains entries,relationships,assets optional. toContent filters archived/visible false, derives sample flags and count; adds content.basePath default '/'. Preserve supplied facts. Uploaded tokens resolved by publisher BEFORE toContent (maps only actual asset-valued fields; no arbitrary URL downloads).
renderPage(path,content=baselineContent) isolated per-call with no global mutation. build({content,outputDir,basePath='/',assetFiles=[]}={}) => outputDir. assetFiles=[{path:'/assets/uploads/<id>.<ext>',bytes:Buffer}]; safe path validation, copy before asset checks. Prefix internal href/src for preview basePath; public baseline unchanged. Empty collections safe, remove hardcoded counts/notices and guide facts.

## Repository interface (all methods async, user-scoped SDK)
createRepository(client) => {getDraft():{entries,relationships,assets}, saveEntry(collection,entry):Entry, archiveEntry(collection,id,archived):Entry, setRelationships(links):Link[], listAssets():Asset[], saveAsset(metadata):Asset, updateAsset(id,patch):Asset, uploadAsset(path,bytes,mime):void, downloadAsset(path):Buffer, listReleases():Release[], createRelease(snapshot):Release, updateRelease(id,patch):Release, getRelease(id):Release}. Throws meaningful errors; check missing rows. Bucket portfolio-originals PRIVATE. Supabase tables content_entries,project_experiences,assets,releases,portfolio_owners. RPC is_portfolio_owner() returns bool. Server always verifies real Supabase user then owner RPC. No service key runtime; privileged key only setup/seed/tests.

## API/UI contract
Origin http://127.0.0.1:4173; cookie-auth HttpOnly sessions; CSRF token returned by GET session/bootstrap; every write sends X-CSRF-Token except login. JSON error {error:{message,fields?:{field:message}}}.
GET /api/admin/session => {user:{email},csrf}; POST /api/admin/login {email,password} => same; POST /api/admin/logout.
GET /api/admin/bootstrap => {user,csrf,entries,relationships,assets,releases,activeReleaseId,configured:true}.
PUT /api/admin/content/:collection/:id body Entry => {entry}; POST /api/admin/content/:collection/:id/archive {archived:boolean} => {entry}; PUT /api/admin/relationships {relationships:[...]} => {relationships}.
POST /api/admin/assets multipart file + visibility private|public => {asset}; PATCH /api/admin/assets/:id {visibility?,archived?} => {asset}; GET /api/admin/assets/:id/file protected original, image inline/PDF attachment.
POST /api/admin/preview => {url:'/admin/preview/<uuid>/'}; GET preview tree protected/no-store/noindex. POST /api/admin/publish =>202 {release}; GET /api/admin/releases => {releases,activeReleaseId}; POST /api/admin/releases/:id/activate => {activeReleaseId}. GET /api/admin/export => draft JSON (owner only).
Publish only one at time, immutable snapshot -> fresh static folder -> atomic pointer; failed jobs preserve prior active output. Restore switches output pointer without editing draft. All uploaded referenced assets must be visibility public to publish; previews may include private assets. No auto remote downloads. JPEG/PNG/WebP <=10MB, PDF<=20MB actual signature validation. Videos external URLs only.
Admin plain dark forms/lists, six content tabs + Assets + Releases; sample/visible/archive/order; id locked on existing; edit all real content fields, tools line array, stages editable structuredJSON with clear errors, project relationships multi-select; asset chooser stores asset:<uuid>. Save draft then Preview/Publish locally, pending/error/empty, unsaved warning, values retained after failure. Existing palette/fonts only. No glyph icons/new cards/decorative dashboards. Vanilla JS fetch; no browser Supabase SDK needed.
