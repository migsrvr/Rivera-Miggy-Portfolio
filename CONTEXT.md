# Portfolio terms

- Draft: the owner's current editable collection of portfolio records and connections.
- Entry: one profile, project, experience, credential, community contribution, or gallery item.
- Connection: an optional association between a project and an experience. Several connections may apply to one project.
- Sample: illustrative content or an association that has not yet been confirmed as factual.
- Asset: an original image or document supplied for use in an entry.
- Public asset: an original the owner permits to be included in the portfolio when referenced.
- Preview: a private view of a fixed draft, used to check changes before publication.
- Release: an immutable version of the content and selected public assets.
- Active release: the version visitors currently see. Restoring a release does not change the draft.
- Portfolio guide: the question-and-answer interface using the active release's supplied facts.
